# 병원이 환자 지갑에 서류를 넣어주는 구조 — 설계

2026-11-09. 사용자 방향: "병원이 처방전·진단서를 우리 서비스에서 PDF로 환자에게 넘겨주게. 병원마다 양식이 다르니 병원을 인증·등록하고, 병원 사람이 로그인해서 환자 지갑에 넣어주게. 법적으로 문제가 되는 부분은 일정 시간 뒤 일정 정보를 폐기하게."

이 문서는 법률 자문이 아니다. "해석"으로 적은 부분은 변호사 검토로 확정해야 한다(docs/legal-checklist.md 질문 목록에 추가).

## 한 줄 요약

환자가 병원에서 종이로 받던 서류(진단서·소견서·처방전 환자 보관용·진료비 영수증)를 **병원이 직접 전자서명해 환자 지갑으로 보낸다.** 우리는 서류를 만들거나 고치지 않는 **배달 통로**다. 중계 서버에는 암호화한 채로 잠깐만 두고, 환자가 받으면(또는 기한이 지나면) 지운다.

## 흐름

1. **병원 등록·인증** — 병원이 가입하면 요양기관명·주소를 심평원 요양기관 목록(이미 앱에 서울 19,929곳 있음)과 대조하고, 사업자등록증·대표 전화 확인·의사 면허번호를 받는다. 확인되면 "인증 병원".
2. **직원 계정** — 병원 관리자가 직원을 초대한다. 역할: 의사(진단서·소견서 서명 가능) / 간호·원무(영수증·처방전 사본 발급, 진단서는 의사 서명 후 전송만).
3. **양식 등록** — 병원이 쓰는 양식 PDF를 올리고 칸(환자명·진단명·소견·날짜·의사 서명 자리)을 지정한다. 양식이 없으면 기본 양식(보건복지부 서식 기준)을 고른다. 병원마다 다른 양식을 그대로 쓸 수 있다.
4. **발급** — 진료가 끝나면 의사 화면에서 "서류 발급" → 양식에 내용이 채워진 PDF 미리보기 → 의사 서명(전자서명) → 환자에게 보내기.
5. **환자 수령** — 환자 앱 "서류함"에 알림. 환자가 열면 기기에 PDF가 저장되고, 중계 서버 사본은 그 즉시 지운다. 7일 안에 안 열면 중계 사본은 자동 폐기되고 병원에 "미수령"으로 돌아간다(병원은 다시 보내거나 종이로 준다).
6. **환자 보관** — 지갑의 서류는 환자 것이다. 환자가 지우거나, 보험 청구·다른 병원에 보여줄 때 직접 공유한다.

## 돈의 방향 — 중요

| 방향 | 가능? | 이유 |
|---|---|---|
| 환자 → 병원: 제증명 수수료(진단서 등) | 가능 | 지금도 종이로 받을 때 내는 돈. 보건복지부 "제증명수수료 상한" 고시 안에서 병원이 정한다. 우리 앱에서 결제만 대신 받는다(PG 정산). |
| 병원 → 우리: 발급 도구 이용료(월 구독 또는 건당) | 가능해 보임 | 병원이 자기 환자에게 서류를 주는 도구를 사는 것. 환자를 특정 병원으로 보내는 대가가 아니다. **변호사 확인 필요.** |
| 우리 → 병원: "서류를 우리 앱으로 보내주면 돈을 드림" | **하지 않는다** | 환자 정보를 넘겨받는 대가(개인정보 제3자 제공의 대가)로 보이거나, 의료법 27조 3항(환자 유인·알선)과 엮일 위험이 크다. 병원 쪽 이득은 "종이 출력·창구 대기 감소, 재발급 문의 감소"로 설득한다. |

## 법적 지점과 설계 대응

| 지점 | 근거(해석) | 설계 대응 |
|---|---|---|
| 진단서는 직접 진찰한 의사만 작성·교부 | 의료법 17조 | 의사 역할 계정만 서명 가능. 서명 없는 진단서는 보낼 수 없게 막는다. |
| 처방전 원본은 약국으로 | 의료법 18조 | 우리는 **환자 보관용 사본**만 다룬다. 약국 전송·조제 연결은 하지 않는다(유인 소지). |
| 환자 기록 사본은 환자 본인(또는 동의받은 대리인) 요청 시 | 의료법 21조 | 환자가 앱에서 "이 병원 서류를 앱으로 받기"에 동의한 경우에만 발급 가능. 가족 대리 수령은 위임 확인 별도. 본인확인(휴대폰 인증 등) 필요. |
| 전자문서의 효력·위변조 방지 | 전자문서법, 전자서명법 | 병원(의사) 전자서명 + 해시. 환자 화면에 "○○병원 서명 확인됨". 우리는 내용을 고치지 않는다. |
| 우리가 서류를 보관하는 것 | 개인정보보호법(처리위탁·파기), 21조 파기 | 병원=위탁자, 우리=수탁자로 위탁 계약. 중계 사본은 **종단간 암호화**(우리는 못 읽음) + **수령 즉시 또는 7일 후 자동 폐기**. 폐기 기록만 남김. |
| 폐기로 불법이 해결되나 | — | 아니다. 폐기는 "필요한 만큼만 보관"(최소보관)을 지키는 수단이다. 발급 자체가 적법해야 한다(위 행들). |
| 병원 직원 계정 보안 | 개인정보 안전성 확보조치 | 직원별 계정·2단계 인증·발급 기록(누가 언제 누구에게 무엇을). 퇴사자 즉시 해제. |

## 서버가 필요하다

병원 계정, 병원 → 환자 기기 간 전달, 암호화 중계, 자동 폐기는 서버 없이는 안 된다. 지금 앱(기기 저장만)으로는 **같은 기기에서 흐름을 보여주는 시연판**까지만 만들 수 있다. 시연판은 화면마다 "시연"으로 표시하고, 실제 서명·인증·중계는 하지 않는다고 밝힌다.

## 단계 (백로그 P1~P5)

- **P1 병원 포털(시연)** — `/hospital`: 요양기관 검색으로 병원 선택(심평원 데이터) → 사업자번호·담당자 입력 → "인증됨(시연)". 직원 추가(이름·역할: 의사/간호·원무). 시연 로그인으로 역할 전환.
- **P2 양식** — 기본 양식 4종(진단서·소견서·처방전 환자 보관용·진료비 영수증) + 병원 양식 PDF 업로드 자리(칸 지정은 다음 단계). 병원별 저장.
- **P3 발급** — 의사 화면 진료 완료 후 "서류 발급": 양식에 소견·처방·진료비 채워 PDF 생성(한글 글꼴 포함), 의사 역할만 진단서·소견서 서명(시연 서명), 환자에게 보내기.
- **P4 환자 서류함** — 지갑에 "서류함": 받은 서류 목록·PDF 보기·저장·공유, 병원 서명 확인 표시, 중계 사본 폐기 기한(7일) 표시와 기한 지난 미수령 처리.
- **P5 수수료 결제(시연)** — 진단서 등 제증명 수수료를 환자가 앱에서 결제(토스 시연), 병원 정산은 실연동 전 표시만.
