# 응급 접근 설계 — 환자가 폰을 못 켜도, 개인정보를 드러내지 않고

2026-11-09. 사용자 질문: "의식이 없어 폰을 못 켜면 우리 서비스는 빛을 못 본다. 기기만 터치하면 보이게 하면, 그 기기를 훔친 사람이 모든 사람의 정보를 본다."

## 원칙 세 가지

1. **환자 몸에 붙은 것이 열쇠다.** 구급대원·병원 기기 혼자서는 아무도 못 본다. 반드시 환자 곁에서 환자가 지닌 것(잠금화면 QR·팔찌·카드)을 읽어야 한다. 기기를 훔쳐도 거기엔 아무 환자 정보도, 열쇠도 없다.
2. **열쇠 반쪽 + 자격 반쪽.** 환자 토큰(반쪽)과 확인된 응급 기관 자격(반쪽)이 함께 있어야 민감한 정보가 열린다. 토큰만 주워도, 기관 기기만 훔쳐도 못 연다. 서버는 암호문만 들고 있어서 서버가 털려도 못 읽는다.
3. **보고 나면 환자가 안다.** 누가 언제 어디서 봤는지 기록되고 환자·가족에게 알림이 간다. 토큰은 쓰고 나면 바꿀 수 있다.

## 정보를 두 층으로 나눈다

| 층 | 내용 | 누가 보나 | 근거 |
|---|---|---|---|
| 1층 · 생명 정보 | 혈액형, 중증 알레르기, 꼭 알아야 할 복용약(항응고제 등), 비상연락처 1명 | 토큰을 읽은 누구나, 즉시, 오프라인에서도 | 아이폰 '의료 ID'가 잠금화면에서 누구에게나 보여주는 수준. 이름·주민번호·주소는 없다 |
| 2층 · 진료 정보 | 복용약 전체, 진단 이력, 최근 진료, 관리약물 이력 | 토큰 + 확인된 응급 기관(119·응급실) 자격, 또는 가족 승인 | 환자가 1층에 무엇을 넣을지 직접 고른다 |

## 환자가 지니는 토큰 — 하드웨어 없이 시작

- **잠금화면 QR**: 앱이 잠금화면 배경 이미지를 만들어 준다(QR + "응급 의료정보" + 1층 글자 일부). 배경으로 설정하면 폰이 잠겨 있어도, 전원 버튼만 눌러도 보인다. 설치 비용 0.
- **아이폰 의료 ID / 안드로이드 긴급 정보**: 앱이 붙여넣을 문구를 만들어 준다. 우리 서비스가 죽어도 남는 안전망.
- **NFC 스티커·카드·팔찌(다음 단계)**: 같은 주소를 담는다. 폰이 꺼져도, 폰이 없어도 된다. 인쇄 주문 기능으로 판다(수익).

QR에는 `https://…/e/<무작위 토큰>#<열쇠 반쪽>`이 들어간다. `#` 뒤는 서버로 전송되지 않는다(브라우저 규칙). 서버는 2층 정보를 암호문으로만 저장한다.

## 읽는 쪽 흐름

1. 구급대원이 아무 폰 카메라로 QR을 읽는다 → 1층 정보가 바로 보인다(서명 검증 포함, 오프라인이면 QR 안의 서명된 1층 정보만).
2. 2층을 보려면 "응급 기관으로 확인" 버튼 → 기관 자격(기관 DID·직원 인증)으로 서버에서 열쇠 나머지 반쪽을 받아 기기 안에서 복호화. 서버는 "누가 언제 어떤 토큰을" 기록만 남긴다.
3. 기관 자격이 없으면(동네 병원 등) **가족 승인**: 비상연락처 가족의 앱에 "○○병원이 2층 정보를 보려 해요 — 1시간 허용" 알림. 이미 있는 가족 연결 기능을 그대로 쓴다.
4. 열람 후 환자 앱에 "11/9 14:02 서울대병원 응급실이 열람" 기록. 환자는 토큰을 한 번에 바꿀 수 있다(배경 이미지 다시 생성).

## 훔쳤을 때 무엇이 보이나

| 훔친 것 | 보이는 것 |
|---|---|
| 응급 기관 기기 | 아무것도. 환자 토큰이 없다 |
| 환자 폰(잠김) | 1층만(의료 ID와 같은 수준). 2층은 기관 자격이 없어 못 연다 |
| 서버 전체 | 암호문과 열람 기록. 열쇠 반쪽이 QR에만 있어 못 읽는다 |
| 팔찌·카드 | 1층만. 환자가 토큰을 바꾸면 그 팔찌는 무효 |

## 솔직한 한계

- 2층은 서버가 있어야 한다(암호문 보관·열람 기록·가족 알림). 지금 앱은 결제 승인 외 서버가 없다. 이것이 서버가 꼭 필요한 첫 기능이다.
- 1층을 잠금화면에 두면 폰을 본 누구나 혈액형·알레르기를 안다. 그래서 환자가 1층 항목을 직접 고르게 한다.
- 구급대가 우리 QR을 읽어 줄지는 보급의 문제다. 1층을 "아무 카메라로 읽히는 보통 웹페이지"로 만드는 이유가 이것이다. 전용 앱을 요구하면 안 읽힌다.
- 폰 배터리가 완전히 나가면 잠금화면 QR도 안 보인다. 그때는 팔찌·카드다.

## 백로그 제안 (서버 없이 할 수 있는 것부터)

- E1 응급 잠금화면 QR 생성 — 1층 정보 선택 → 배경 이미지 저장 → "잠금화면으로 설정하는 법" 안내. QR은 서명된 1층 정보 자체를 담아 오프라인 열람.
- E2 `/e/<token>` 열람 페이지 — 아무 폰 카메라로 열리는 보통 웹페이지, 1층 즉시 표시, 2층은 "준비 중(기관 확인 필요)".
- E3 의료 ID 문구 생성 — 아이폰·안드로이드 긴급 정보에 붙여넣기.
- E4 (서버) 2층 암호문 보관·열쇠 반쪽·열람 기록·가족 승인.
- E5 NFC 스티커·카드 주문.
